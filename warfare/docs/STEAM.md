# Shipping Warfare on Steam

This is the checklist for turning the repository into a Steam build. Nothing here needs code changes except the
optional Steamworks library.

## 1. Build a Windows package

On a **Windows machine with JDK 21** (the runtime that is bundled is the one you build with):

```bash
cd warfare
gradlew.bat :desktop:packageApp
```

Output: `desktop/build/jpackage/Warfare/` containing `Warfare.exe`, a trimmed Java runtime and the assets
(`lib/assets`: map, fonts, icons, flags). Upload that whole folder as the depot. On Linux/macOS the same task makes a
native app image for that OS. `gradlew :desktop:installDist` produces a plain zip layout (`bin/warfare` + jars + assets)
that needs Java 21 installed.

The launcher finds its assets from the location of its own jars, so the folder can be installed anywhere.

## 2. Steam depot and launch option

* App type: game. One depot, Windows 64-bit, content root = the `Warfare` folder.
* Launch option: executable `Warfare.exe`, working directory empty.
* `steam/app_build.vdf` and `steam/depot_build.vdf` are templates; replace `APPID` / `DEPOTID`.

## 4. Steamworks library (optional, needed for achievements and overlay)

The bridge (`desktop/.../Steam.java`) uses reflection, so the project builds without it. To enable it:

1. Add `com.code-disaster.steamworks:steamworks4j:1.9.0` to `desktop/build.gradle` (`runtimeOnly`) and ship its native
   libraries (`steam_api64.dll`, `steamworks4j.dll`) next to the jars.
2. Put `steam_appid.txt` (your app id) next to the executable while testing outside Steam.
3. Launch through Steam. If initialisation fails the bridge disables itself and the game continues with local
   achievements. The bridge has **not** been tested against a real Steam client from the build environment.

## 5. Cloud saves

Use **Steam Auto-Cloud** (no code needed). In the Steamworks app settings add:

* Root: `WinMyDocuments`/user profile root, subdirectory `.warfare`
* Pattern: `*.sav` and `profile.properties`, `settings.properties`

Saves live in `~/.warfare/` (`slot1-3.sav`, `autosave.sav`, `ironman.sav`).
